## 4. ⚠️ 차트 수정 방법 (가장 중요 — 수치를 바꾸면 반드시 읽을 것)

**모든 차트 좌표는 하드코딩된 계산값입니다.** 데이터를 바꾸면 좌표도 손으로 다시 계산해야 합니다.

### 4-1. CSS 막대 차트 (`.brow` / `.srow`)
`style="width:XX%"`가 막대 길이입니다. 해당 figure 안에서 **가장 큰 값 = 100%(또는 96~98%)**로 잡고 비례 배분합니다.
음수 막대는 `class="bar negdir"` + `left`를 기준선보다 왼쪽으로 지정.
기준선은 `.grid0`(0선) 또는 `.refline`(100% 등 참조선).

예) QoQ 차트: 최대값 샌디스크 +286% → `width:100%`, 키옥시아 +121% → `121/286 = 42.3%`.
**새 종목을 추가해 최대값이 바뀌면 그 차트의 모든 막대를 재계산해야 합니다** (실제로 샌디스크 추가 때 전부 다시 계산했음).

### 4-2. 빅테크 주가 SVG (선형 눈금)
`viewBox="0 0 720 320"`, 지수값 → y좌표 변환식:

```
y = 138.2 - (지수값 - 100) * 4.73
```
(가로 그리드: 120→43.6, 110→90.9, 100→138.2, 90→185.4, 80→232.7)

x좌표 8개 시점(’25말~7월): `40, 124, 209, 293, 377, 461, 546, 630`

검산: 아마존 117.7 → 138.2 − 17.7×4.73 = **54.5** (실제 `55` 사용)

### 4-3. 반도체 주가 SVG (로그 눈금)
`viewBox="0 0 720 322"`, 값의 범위가 108~958로 넓어 **로그 스케일** 사용:

```
y = 268 - (log10(지수값) - 1.9542) * 218
```
(가로 그리드: 1000→40, 800→61.1, 400→126.8, 200→192.4, 100→258)

x좌표 8개 시점: `40, 121, 203, 284, 366, 447, 529, 610`
(오른쪽 `618`부터 종목명 라벨 배치)

검산: 샌디스크 511.8 → log10=2.7092 → 268 − 0.755×218 = **103.4** (실제 `103` 사용)

### 4-4. 스택 컬럼 차트 (연간 CapEx)
`.col .stack .seg`의 `height:XXpx`가 각 기업 기여분. 탭1(2023~27E)은 **1px ≈ $3.8B**, 탭3(2016~20)은 값이 훨씬 작아 **1px ≈ $0.59B(= 값 × 1.7)** 로 별도 스케일을 쓴다. 두 차트의 막대 높이를 서로 비교하면 안 된다.
2027E는 실측이 아니라 점선 박스(`.ghost`)로 표현.

### 4-5. 탭3 국면 지도 SVG (§11)
`viewBox="0 0 720 310"`. 시간축은 **월 단위 선형**:

```
x = 100 + (2017년 1월부터의 개월 수) × 16.67
```
(2017-01→100, 2018-01→300, 2019-01→500, 2020-01→700)

행 y좌표(각 밴드 높이 20px): 반도체 주가 52 / 빅테크 주가 97 / DRAM 계약가 142 / 메모리 영업이익 187 / 빅테크 CapEx 232.
점선 세로선 2개가 핵심 시각 요소 — 반도체 고점 `x=367`(’18.5), 빅테크 고점 `x=433`(’18.9), 그 사이가 "시차 4개월".
붉은 밴드(`--up`)=확장, 푸른 밴드(`--down`)=수축. **시점을 바꾸면 밴드의 `x`와 `width`를 동시에 고쳐야 한다**(width = 끝x − 시작x).

### 5-3. PDF 재생성
HTML 앞에 doctype 래퍼를 씌운 임시 파일을 만들어 Edge headless로 인쇄합니다(래퍼 없으면 한글 인코딩 깨짐).

**⚠️ 함정 3개 — 아래 스크립트를 그대로 쓸 것.**
1. `&` 호출 연산자로 Edge를 실행하면 **PDF가 써지기 전에 반환**되어 파일이 조용히 갱신되지 않는다(에러도 안 남). `Start-Process -Wait` 필수.
2. `--user-data-dir`을 지정하지 않으면 실행 중인 Edge가 기본 프로필을 잠가서 **exit 13**으로 실패한다.
3. 출력 경로를 OneDrive 폴더로 직접 주면 실패한 사례가 있다. 임시 폴더에 쓴 뒤 복사한다.

```powershell
$tmp = "C:\Users\ocarr\AppData\Local\Temp\claude\big4pdf"
New-Item -ItemType Directory -Force -Path "$tmp\edgeprof" | Out-Null
$c = Get-Content -Raw -Encoding UTF8 "big4-semis-q2-2026-review.html"
('<!doctype html><html lang="ko"><meta charset="utf-8">' + $c + '</html>') | Out-File -Encoding utf8 "$tmp\print.html"
$edge = "C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"
```

## 7. 리포트의 뼈대 논지 (수정 시 훼손하지 말 것)

1. **"주가 반응 ≈ 수요 증거 − 지출 서프라이즈"** — 시장의 심판 기준이 '지출 규모'에서 '증거 제시력'으로 이동. MSFT·아마존(증거 제시) vs 알파벳·메타(지출 선행)의 ±15%p 스프레드가 근거.
2. **반도체 주가의 방아쇠는 자기 실적이 아니라 빅테크 어닝콜** — 사상 최대 실적에도 급락, 아마존 발표일에 +27~30% 폭등한 7월이 증거.
3. **DRAM과 NAND의 사이클 시계가 다르다** — DRAM ~2028, NAND ~2027 상반기. 가장 많이 오른 NAND가 역설적으로 시계가 짧다.
4. **엔비디아 소외의 의미** — 매출 +85%에도 주가 +7.6%. AI 병목이 GPU에서 HBM·NAND로 이동했음을 주가가 표현.
4-b. **7월 급락 = 사이클 붕괴가 아니라 메모리 포지션 청산** — TSMC(+1%)와 엔비디아(0%)만 6월 고점을 지켰다. 사이클 자체가 의심받았다면 파운드리·GPU도 함께 무너졌어야 함.
5. **하방 선행지표 4가지** — ①클라우드 성장률 감속 ②백로그 증가율 둔화 ③CapEx 가이던스 첫 하향 ④메모리 인플레 루프의 빅테크 마진 압박.

- 스타일 선호: **결론 먼저**, 표·차트 중심의 시각화, 보기 좋은 디자인
- 작업 중 추가 요청을 자주 던지는 편 → 요청 시 기존 리포트를 확장하는 방향으로 대응
- 완료 시 카카오톡으로 링크 전송을 원함

## 11. 삽질 기록 (같은 함정 피하기)

| 문제 | 해결 |
|---|---|
| Vercel 배포가 계속 `BLOCKED` | 프로젝트 고유 문제. 새 프로젝트 생성이 답 (계정·플랜 정상이어도 발생) |
| vercel CLI가 배포 후 종료 안 됨 | `Start-Process cmd /c "... > log"`로 분리 실행 후 로그 확인 |
| `vercel project rm --yes` 옵션 없음 | REST API `DELETE /v9/projects/{name}` 사용 |
| `vercel ls`가 개인 스코프에서 빈 목록 | 프로젝트가 팀 스코프에 있음. `?teamId=` 붙여 조회 |
| PDF 한글 깨짐 | doctype+charset 래퍼를 씌운 임시 파일로 인쇄 |
| **PDF가 조용히 갱신 안 됨** | `& $edge ...`는 파일 쓰기 전에 반환됨. `Start-Process -Wait` 필수 (5-3 참조). 크기·타임스탬프로 검증 |
| **Edge headless exit 13** | 실행 중인 Edge가 기본 프로필 잠금. `--user-data-dir`을 임시 폴더로 지정 |
| **`vercel deploy`가 프로젝트명 400 에러** | `.vercel/`이 사라진 상태. 폴더명 "big4 review"의 공백 때문에 새 프로젝트 생성이 거부됨. `vercel link --project big4-report --scope ...`로 재링크 (5-2 참조) |
| `Read`로 PDF 확인 불가 | pdftoppm 미설치. PDF 시각 검증은 불가하니 HTML 렌더링으로 대신 확인 |
| 브라우저 `navigate` 타임아웃 | 이 환경의 Browser pane이 불안정. 렌더링 검증은 배포 후 `Invoke-WebRequest`로 문자열 매칭 |
| 차트에 종목 추가 후 비율 깨짐 | 최대값 기준 `width:%`를 **전부** 재계산해야 함 (4-1 참조) |
